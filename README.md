# Dangler Tune 🎸🩸

Гитарный тюнер для рок-группы Dangler. Базовый строй — **Drop B**, плюс Standard E, Drop D, D Standard, Eb, Drop C.
Металлический минимализм: гигантская нота во весь экран, портрет и ландшафт — кровь сама и есть прибор.

## Навигация: только свайпы

Никаких шестерёнок и шторок — три страницы в `HorizontalPager`:

| Свайп | Страница |
|---|---|
| ◀ | **СТРОЙ** — карточки строёв с мини-чипами струн, тап выбирает и возвращает в тюнер |
| ● | **ТЮНЕР** — нота на весь экран, кровь внутри неё и есть прибор |
| ▶ | **НАСТРОЙКИ** — темы, точность, эффекты, обновление |

На тюнере — нота на весь экран и точки страниц (тюнер на средней).
**Тап по экрану** — вылазят только 6 струн строя, ещё тап — прячут. Никаких дублей ноты, никакого «тишина».

## Звук: алгоритм детекции

- **YIN** (de Cheveigné & Kawahara) поверх кадров 4096 @ 44100 Гц — устойчив к гармоникам гитары
- Параболическая интерполяция периода → точность ~1 цент
- RMS-gate против тишины, медианный фильтр по 5 кадрам против выбросов
- Центы считаются относительно **ближайшей струны выбранного строя**
- Файлы: `dsp/YinPitchDetector.kt`, `audio/AudioRecorder.kt`, `model/Tunings.kt`

## HERO: кровавая нота (`ui/components/BloodNote.kt`)

Стрелку-шкалу и строб выкинули — теперь сама нота и есть прибор:

- Стальной глиф (Black, ~60% высоты экрана, тиснение) наполняется кровью **слева** (ниже строя) или **справа** (выше), уровень = `|cents| / 50`
- Заливка строго внутри глифов: `saveLayer` + маска текста + `BlendMode.SrcIn`
- Центы сглажены (`animateFloatAsState` tween 120мс) + мёртвая зона ±2.5¢ на смену стороны — волна плывёт, а не дёргается
- В точке: заливка на 100% + кислотная вспышка + дыхание glow + вибрация
- По центру — едва видимая риска-датчик
## Хроматика: своя vs чужая (`ui/TunerViewModel.kt`)

Тюнер слышит **любую** ноту, а не только струны строя:

- Центы всегда хроматические — относительно ближайшей ноты 12-TET, осмысленны везде
- Нота из строя льётся **кровью**, чужая — **янтарём** (`chroma` в теме) — видно сразу
- В полоске струн (по тапу) активная струна повторяет логику: кровь / янтарь / кислота в точке
- Переключение нот быстрое: медиана по 3 кадрам, дебаунс тишины 120мс
- Задник — `MetalBackdrop`: шлифовка металла + виньетка

## Дизайн-система: Gloryhole-base, кровь Dangler

UI-кит (`ui/components/DanglerKit.kt`) портирован по механике из GloryholeVPN, палитра своя:

| Приём из Gloryhole | Как у нас |
|---|---|
| `AutumnGlassCard` (clip 24dp + glass + border 1dp, без теней) | `DanglerGlassCard`, бордер `blood 0x40FF2E2E` |
| `AutumnStatusPill` (дышащий бордер через `animateColorAsState`) | `DanglerStatusPill` (резерв) |
| `SettingsItemSwitch` (ряд 16dp + иконка + Switch) | `DanglerSwitchRow` |
| `DevTuningDialog`-слайдеры (акцентный thumb, моно-значения) | `DanglerSliderRow`, цифры — `Monospace` |
| Дыхание `tween + Reverse` (Blobatar / TactileConnectButton) | Дыхание glow ноты |

Темы (свои, не осенние): **Brutal Black**, **Blood Stage**, **Acid Rehearsal**. В точке всегда кислотный зелёный, расстройка — кровь.

## Обновление из приложения

Без Google Play: приложение само проверяет GitHub Releases и ставит APK (`update/UpdateManager.kt` + FileProvider).

- Проверка: `GET api.github.com/repos/badaiir/Dangler-Tune/releases/latest`, сравнение версий численно (1.10 > 1.2)
- Скачивание с прогрессом в `cacheDir`, установка через `ACTION_VIEW` + FileProvider
- Если запрещены неизвестные источники — ведёт в системные настройки, потом установка в один тап
- Тихая проверка при старте: бейдж «ОБНОВА ↓» на тюнере → прыжок на страницу настроек

Как выкатить обнову:

```bash
# 1. bump versionName/versionCode в app/build.gradle.kts
# 2. коммит + тег:
git commit -am "v1.3 ..."
git tag v1.3
git push origin main --tags   # → workflow Release APK → GitHub Release с APK
```

## Сборка

Слабый ПК не мучаем — билдим через GitHub Actions:

```bash
git push origin main   # → Actions → Build APK → Artifacts: dangler-tune-apk
```

Локально: `./gradlew assembleDebug`. Установка: `adb install -r app-debug.apk`.
